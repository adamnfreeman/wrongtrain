---
name: todo
description: Put something on the WrongTrain to-do list without working on it. Use when Adam or Andrea types /todo followed by an idea, a bug or a request.
---

Add what they typed to the to-do list. Do not start on it, investigate it or suggest a fix now,
even if it looks quick; that comes later, when they pick it from the list.

1. Read CLAUDE.md's numbered list under "Where things stand" and find the highest number.
   Add the new item after the last one, numbered one higher: a bold short title, then their
   request in plain words, plus where it lives in the code if you already know (don't go looking).
   If it clearly adds to an existing item, still give it its own number and say "(see N)".
2. Add a row to the project sheet's To-dos tab (link in CLAUDE.md, "Working together"): #, Status
   Open, To-do (the short title), Details, Who (whoever asked: Adam or Andrea), Added (today's
   date, like "Oct 17"), Done on empty. Use the Google Sheets connector; if it isn't connected,
   say so and show the row to add.
3. Leave the CLAUDE.md change uncommitted; it goes in with their next /save or /done.
4. Reply in one line: "Added #N: <short title>."
